# Умная система управления дорожным трафиком (УСУДТ)

УСУДТ предназначена для анализа дорожной ситуации и поддержки принятия решений по настройке светофорного регулирования на участке улицы Северной в Краснодаре, включающем пересечения с улицами Красной, Рашпилевской, Головатого, Садовой и Фрунзе.

Система предусматривает обработку транспортных измерений, оценку интенсивности движения, краткосрочное прогнозирование на 5, 10 и 15 минут, сравнение допустимых светофорных программ, регистрацию решений инженера, учёт неисправностей и обращений.

УСУДТ дополняет действующие АСУДД и ИТС. Выбор и подтверждение программы выполняет инженер по организации дорожного движения. Непосредственное управление светофорными контроллерами не предусмотрено.

**Основные технологии:** Python, FastAPI, PostgreSQL, SQLAlchemy.
