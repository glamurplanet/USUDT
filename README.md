# УСУДТ

Серверное приложение для анализа транспортного движения на пяти пересечениях ул. Северной в Краснодаре. Система принимает измерения, рассчитывает простую оценку интенсивности, сравнивает допустимые программы по данным согласованной транспортной модели и регистрирует решения инженера. Команды светофорным контроллерам не отправляются.

## Технологии
Python 3.11+, FastAPI, SQLAlchemy, PostgreSQL 16. Браузерный интерфейс API: `/docs`; главная страница: `/`.

## Запуск на Windows (PowerShell, VS Code)

1. Установите Python 3.11+, Git и Docker Desktop либо PostgreSQL 16.
2. Откройте папку проекта в VS Code и выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

3. Проверьте пароль в `.env`. Для запуска PostgreSQL через Docker выполните `docker compose up -d db`. Если используется установленный PostgreSQL, создайте пользователя `usudt`, базу `usudt` и установите свои параметры подключения.
4. Создайте таблицы и справочники, запустите приложение:

```powershell
python -m app.init_db
uvicorn app.main:app --reload
```

5. Откройте `http://127.0.0.1:8000/` и `http://127.0.0.1:8000/docs`.

## Проверка

```powershell
pytest -q
```

CSV с примерами структуры входных сообщений находится в `samples/measurements.csv`. В нём использованы исторические тестовые даты. Для прогноза и сравнения необходимо загрузить 12 или более разных минутных измерений за последние 15 минут. При их отсутствии система корректно возвращает сообщение о недостатке данных.

## Основные маршруты API

| Метод и путь | Назначение |
| --- | --- |
| `GET /api/signals` | Пять светофорных объектов |
| `POST /api/measurements` | Приём JSON |
| `POST /api/measurements/csv` | Загрузка CSV |
| `GET /api/forecast/{code}` | Прогноз на 5, 10 и 15 минут |
| `POST /api/programs`, `POST /api/estimates` | Каталог программ и расчёты модели |
| `GET /api/programs/compare/{code}` | Сравнение до трёх утверждённых программ |
| `POST /api/decisions` | Черновик решения |
| `POST /api/decisions/{id}/confirm` | Подтверждение автором и подготовка пакета |
| `POST /api/incidents`, `POST /api/appeals` | События и обезличенные обращения |
| `GET /api/report` | Сводная статистика |

Ограничения первоначальной версии: базовый прогноз для трёх горизонтов возвращает одинаковую интенсивность; проверки средней абсолютной ошибки по накопленным данным, полноценный ролевой доступ, интеграция с АСУДД и выгрузка PDF остаются предметом следующих этапов. Ввод режима выполняется отдельно в АСУДД. Не использовать проект для управления дорожным движением без проверки и согласования.

## Публикация в собственный GitHub

Создайте пустой публичный репозиторий `USUDT`, затем в терминале в папке проекта выполните:

```bash
git init
git add .
git commit -m "Initial project configuration"
git branch -M main
git remote add origin https://github.com/USERNAME/USUDT.git
git push -u origin main
```

Замените `USERNAME` своим именем пользователя GitHub. Не загружайте файл `.env` и пароли. После публикации вставьте ссылку и собственный скриншот страницы репозитория в третий раздел отчёта ЛР4.
